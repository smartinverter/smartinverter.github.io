Grid-Aware Smart Inverter Framework & Modular EMT SI Toolbox

A communication-less, grid-aware SI control framework featuring active/reactive power probing alongside an open-source dynamic Electromagnetic Transient (EMT) Smart Inverter toolbox.

S. Gokul Krishnan Mohd. Asim Aftab Shehab Ahmed Charalambos Konstantinou
Get Smart Inverter Toolbox Read Abstract

Abstract

Widespread deployment of smart inverters (SIs) in distribution feeders introduces coordination challenges as autonomous actions become electrically coupled through feeder impedance. Existing coordination methods generally require topology, communication infrastructure, or offline tuning. To address this, this work introduces a communication-less, grid-aware SI framework where each inverter locally estimates its equivalent grid resistance ($R_g$) and reactance ($X_g$) via active/reactive power ($P-Q$) probing and dynamically selects the optimal control mode and curves.

Dynamic EMT Smart Inverter Toolbox

Unlike existing tools that are either proprietary, quasi-static (QSTS), or limited by fixed control modes, this modular toolbox allows dynamic reference generation and seamless real-time mode switching across standard IEEE 1547 functions.

Constant Power Factor (CPF)

Fixed power factor operation with dynamic reactive power limits based on instantaneous inverter capability.

Constant Reactive Power (CRP)

Maintains constant reactive power injection/absorption commands within capability boundaries.

Volt-VAr (VV) Control

Piecewise linear voltage-dependent reactive power support with flexible piecewise curve breakpoints.

Volt-Watt (VW) Control

Active power curtailment as a function of PCC voltage magnitude to mitigate severe overvoltages.

Grid-Aware Control Architecture

3-Stage autonomous voltage support framework

Stage I

Local Grid Characterization

Applies small sequential active ($\Delta P$) and reactive ($\Delta Q$) perturbations to estimate local $R_g$ and $L_g$ using filtered dq-frame components.

Stage II

Adaptive Mode & Curve Design

Determines local voltage impact margins ($\Delta V_P, \Delta V_Q$) to adaptively build custom VV/VW curves and select optimal operating modes.

Stage III

Emergency Voltage Support

Monitors RoCoV ($\dot{V}$) and PCC voltage to trigger smooth hyperbolic tangent ($tanh$) reactive power emergency injection/absorption during severe disturbances.
